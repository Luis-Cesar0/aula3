# Formulário com HTML e CSS

Exemplo de formulário com campos de nome, e-mail e CPF, acompanhado de estilos para organizar e apresentar os controles.

## Como visualizar

Abra index.html em um navegador. O formulário é apenas demonstrativo: o repositório não contém integração para enviar ou armazenar os dados.
